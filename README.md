# Mahjong Christmas

A one-player, Christmas-themed Mahjong Solitaire game built with Godot 4.

## Included

- Solvable single-player deals with matching pairs.
- Randomised 6×6 foundation and two supported raised piles.
- Touch drag to rotate the board and pinch to zoom.
- Android export configuration for the separate Mahjong Christmas application.

## Open and run

1. Open `project.godot` in Godot 4.7 or later.
2. Run the project for desktop testing, or use the Android export preset for a device build.

Generated Godot cache, Android build output, signed packages, and local signing files are deliberately excluded from version control.
